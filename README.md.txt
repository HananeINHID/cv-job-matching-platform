# Job Scraper - Maroc

## Installation
pip install -r requirements.txt

## Utilisation
python scraper_scheduler.py

## Description
Script de scraping automatique des offres d'emploi au Maroc.
S'exécute automatiquement chaque jour à 08:00.

## Sites scrapés
- Rekrute.com
- Emploi.ma
- Tanitjobs.com
- Optioncarriere.ma
- Marocannonces.com
